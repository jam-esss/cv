# 📦 cv

A Laravel CV website inspired by my love for Cyberpunk, blending my professional profile with neon-lit, futuristic
visuals and interactive elements.

## ℹ️ Overview

As a huge fan of Cyberpunk, I built this CV website with Laravel to reflect both my professional journey and my passion
for immersive, futuristic aesthetics. The site showcases my experience, skills, education, and projects, all wrapped in
a dark, neon-accented design that pays homage to the world of Night City. Behind the scenes, Laravel ensures smooth
content management, scalability, and security, while the frontend delivers an engaging, responsive, and visually
striking experience.

## ⬇️ Installation

```bash
git clone https://github.com/jam-esss/cv.git
cd cv

composer install

cp .env.example .env
php artisan key:generate

# Configure your database in .env before continuing

npm install
npm run build

php artisan migrate
php artisan serve
```

On some IDE's certain shortcuts can be made for ease of use. Here are my PHPStorm ones:

```
PHP Script
File: \cv\artisan
Arguments: serve
```

```
npm
File: \cv\package.json
Command: run
Scripts: dev
```
